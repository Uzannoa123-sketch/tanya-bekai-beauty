# הפעלת האתר ומערכת התורים – מדריך חיבור

המדריך מסביר מה צריך כדי שהאתר יעלה לאוויר, ואיך מחברים את מערכת התורים, אישורי הוואטסאפ והיומן.

## איך המערכת עובדת

```
לקוחה ממלאת טופס באתר
        │
        ▼
/api/booking  ──►  נשמר במאגר (Supabase) בסטטוס "ממתין לאישור"
        │
        ├──► וואטסאפ לטניה: פרטי הבקשה + קישור לאישור
        └──► וואטסאפ ללקוחה: "הבקשה התקבלה, ממתינה לאישור"
                           │
טניה לוחצת על הקישור ◄─────┘
בוחרת תאריך ושעה מדויקים → "אישור התור"
        │
        ├──► סטטוס "אושר" + אירוע ביומן Google (אם מחובר)
        └──► וואטסאפ ללקוחה: "התור שלך אושר"
                           │
פעם ביום ב-18:00 (שעון ישראל, בשעון חורף 17:00) ──► תזכורת בוואטסאפ לכל תור מאושר ל-30 השעות הקרובות
```

**בקשה היא לא תור.** התור נחשב מאושר רק אחרי שטניה לוחצת "אישור התור". עד אז הלקוחה רואה "ממתין לאישור".

**בלי שרת מחובר האתר עדיין עובד.** אם השרת לא זמין, למשל באחסון סטטי, הלקוחה מקבלת כפתור לשליחת כל פרטי הבקשה לטניה בוואטסאפ. כלום לא נשמר, ולא מוצגת הודעה שהבקשה התקבלה.

**אין זמינות מומצאת.** כל עוד יומן Google לא מחובר, הלקוחה בוחרת חלק ביום (בוקר / צהריים / ערב), וטניה קובעת את השעה המדויקת כשהיא מאשרת. אחרי החיבור מוצגות רק שעות שבאמת פנויות ביומן.

## שלב 1: אחסון האתר – Vercel

1. פותחים חשבון ב-[vercel.com](https://vercel.com) עם חשבון ה-GitHub.
2. **Add New → Project** ובוחרים את המאגר `tanya-bekai-beauty`.
3. לוחצים **Deploy**. אין צורך בהגדרות build.
4. מחברים דומיין ב-**Settings → Domains**, למשל `tbcosmetology.co.il`.

כבר בשלב הזה האתר עובד במלואו, ובקשות לתור נשלחות לטניה בוואטסאפ.

## שלב 2: שמירת בקשות – Supabase

1. פותחים פרויקט ב-[supabase.com](https://supabase.com). כדאי לבחור אזור באירופה.
2. **SQL Editor → New query**, מדביקים את התוכן של `supabase/schema.sql` ולוחצים **Run**.
3. ב-**Project Settings → API** מעתיקים את `Project URL` ואת `service_role key`.
4. ב-Vercel, תחת **Settings → Environment Variables**, מוסיפים:
   - `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`
   - `BOOKING_LINK_SECRET`: מחרוזת אקראית ארוכה (אפשר ליצור אחת עם `openssl rand -hex 32`)
   - `CRON_SECRET`: מחרוזת אקראית נוספת
   - `SITE_URL`: כתובת האתר, למשל `https://tbcosmetology.co.il`

הטבלה סגורה לגישה מהדפדפן (Row Level Security). רק השרת יכול לקרוא ולכתוב, והמפתח הסודי לא מגיע אף פעם לדפדפן.

## שלב 3: אישורים בוואטסאפ – WhatsApp Business Cloud API

שליחת הודעות אוטומטיות דורשת את ה-API הרשמי של Meta. אפליקציית WhatsApp Business הרגילה בטלפון לא מספיקה.

**חשוב לדעת מראש:** מספר שמחובר ל-Cloud API לא יכול לשמש באותו זמן באפליקציית וואטסאפ רגילה (יש אפשרות "coexistence" שמאפשרת את שניהם, בכפוף לזמינות אצל Meta). לכן מומלץ אחת משתי האפשרויות:
- **מספר נפרד לשליחת הודעות המערכת**, והמספר 054-682-4499 נשאר לשיחות רגילות עם לקוחות. זו האפשרות המומלצת.
- או ספק מורשה (BSP) כמו Twilio, 360dialog או ספק ישראלי, שמנהל את החיבור עבורך. הקוד ב-`api/_lib/whatsapp.js` הוא המקום היחיד שצריך לשנות.

השלבים:
1. יוצרים אפליקציה ב-[developers.facebook.com](https://developers.facebook.com) ומוסיפים את המוצר **WhatsApp**.
2. מחברים חשבון WhatsApp Business ומספר טלפון, ומאמתים את העסק ב-Business Manager.
3. יוצרים **System User** עם הרשאת `whatsapp_business_messaging` ומפיקים טוקן קבוע.
4. ב-Vercel מגדירים: `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID`, `OWNER_WHATSAPP_NUMBER=972546824499`.
5. ב-**WhatsApp Manager → Message templates** יוצרים חמש תבניות בעברית (שפה: Hebrew, קטגוריה: Utility):

| שם התבנית | למי | נוסח מוצע |
|---|---|---|
| `tb_new_request` | טניה | בקשה חדשה לתור מ-{{1}} ({{2}}). נושא: {{3}}. מועד מבוקש: {{4}}, {{5}}. הערה: {{6}}. לאישור או דחייה: {{7}} |
| `tb_request_received` | לקוחה | היי {{1}}, הבקשה שלך לתור ב-{{2}} ({{3}}) התקבלה. טניה תחזור אלייך עם אישור. התור ייקבע סופית רק אחרי האישור. |
| `tb_appointment_confirmed` | לקוחה | היי {{1}}, התור שלך אושר: {{2}} בשעה {{3}}. כתובת: {{4}}. נתראה! TB Cosmetology |
| `tb_request_declined` | לקוחה | היי {{1}}, המועד שביקשת לא פנוי. טניה תיצור איתך קשר כדי לתאם מועד אחר. |
| `tb_appointment_reminder` | לקוחה | היי {{1}}, תזכורת לתור שלך מחר, {{2}} בשעה {{3}}, ב{{4}}. אם צריך לשנות, אפשר לענות להודעה הזו. |

אישור תבנית לוקח בדרך כלל בין כמה דקות לכמה שעות. Meta גובה תשלום על הודעות תבנית לפי המחירון העדכני שלה, ובאתר שלה אפשר לבדוק את המחיר לישראל.

השרת מקבל בקשות רק כשגם המאגר וגם וואטסאפ מחוברים, כדי שלא תישמר בקשה שטניה לא יודעת עליה. עד אז הבקשות נשלחות לטניה בוואטסאפ דרך הכפתור באתר.

## שלב 4 (רשות): יומן Google ושעות פנויות אמיתיות

1. ב-[console.cloud.google.com](https://console.cloud.google.com) יוצרים פרויקט, מפעילים את **Google Calendar API** ויוצרים **Service Account** עם מפתח JSON.
2. ביומן של טניה: **הגדרות → שיתוף עם אנשים ספציפיים**, מוסיפים את כתובת ה-Service Account עם הרשאה **"ביצוע שינויים באירועים"**.
3. ב-Vercel מגדירים:
   - `GOOGLE_CALENDAR_ID` (בדרך כלל כתובת הג'ימייל של טניה)
   - `GOOGLE_SERVICE_ACCOUNT_EMAIL`, `GOOGLE_PRIVATE_KEY` (מתוך קובץ ה-JSON)
   - `WORK_HOURS`, למשל `09:00-19:00`: **רק אחרי שטניה מאשרת את השעות**
   - `SLOT_MINUTES`, `APPOINTMENT_MINUTES` (ברירת מחדל: 60)

מהרגע הזה האתר מציג רק שעות שפנויות ביומן, וכל תור שמאושר נכנס ליומן אוטומטית.
